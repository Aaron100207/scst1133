# SCST1133 — Data Engineering Ecosystem

This repository is the official exercise submission space for students enrolled in **SCST1133 Data Engineering Ecosystem** at the Faculty of Computing, Universiti Teknologi Malaysia.

## Repository Purpose

Students use this repository to:

- submit practical exercises;
- practise Git and GitHub workflows;
- document learning using Markdown;
- build a visible record of progress; and
- receive feedback through Pull Requests.

Course website: [SCST1133 Data Engineering Ecosystem](https://drshahizan.github.io/scst1133/)

## Submission Workflow

1. Fork this repository.
2. Clone your fork using GitHub Desktop or Git.
3. Create a branch named `exercise-XX-matric-number`.
4. Create your personal folder using the required structure.
5. Add the exercise files and complete the exercise README.
6. Commit using a meaningful message.
7. Push the branch to your fork.
8. Open a Pull Request to the `main` branch.
9. Complete every item in the Pull Request checklist.
10. Wait for feedback before making further changes.

Read [STUDENT-GUIDE.md](STUDENT-GUIDE.md) for detailed instructions.

## Required Folder Structure

```text
submissions/
└── section-XX/
    └── MATRIC-NUMBER-name/
        └── exercise-XX/
            ├── README.md
            └── supporting-files
```

Example:

```text
submissions/section-03/A24CS0123-nur-aisyah/exercise-01/
```

Use lowercase letters for names and exercise folders. Use hyphens instead of spaces.

## Submission Requirements

Every submission must include:

- student name, matric number and Section;
- exercise title and completed work;
- evidence such as screenshots, code or output;
- a short reflection; and
- references, acknowledgements and AI-use disclosure.

Use the [exercise submission template](templates/exercise-template.md).

## Important Rules

- Submit only your own work.
- Do not upload passwords, API keys, tokens or private information.
- Do not modify another student's folder.
- Do not place files directly in a Section folder.
- Cite external sources and declare substantial AI assistance.
- Test every file and link before opening a Pull Request.
