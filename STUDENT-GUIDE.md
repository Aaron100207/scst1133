# Student Submission Guide

## 1. Fork the Repository

Open the repository, select **Fork**, and create the fork under your GitHub account.

## 2. Clone Your Fork

In GitHub Desktop, select **File → Clone Repository**, choose your fork and select a local folder.

## 3. Create a Branch

Use:

```text
exercise-XX-matric-number
```

Example: `exercise-01-a24cs0123`

Do not work directly on `main`.

## 4. Create Your Submission Folder

```text
submissions/section-XX/MATRIC-NUMBER-name/exercise-XX/
```

Example:

```text
submissions/section-03/A24CS0123-nur-aisyah/exercise-01/
```

## 5. Prepare the Exercise README

Copy `templates/exercise-template.md` into your exercise folder and rename it `README.md`. Complete every section.

## 6. Add Evidence

Evidence may include source code, Markdown files, screenshots, diagrams, output files or working links. Use clear file names.

## 7. Commit and Push

Use a meaningful message such as:

```text
Complete Exercise 01 GitHub profile
```

Avoid messages such as `update`, `work` or `final`.

## 8. Open a Pull Request

Use this title:

```text
[Section XX] Exercise XX - Matric Number - Name
```

Complete the Pull Request checklist before submission.

## Responding to Feedback

Edit the same branch, commit the corrections and push again. The Pull Request will update automatically.

## Common Mistakes

- submitting to the wrong Section;
- using spaces in folder names;
- changing another student's work;
- omitting the exercise README;
- uploading private credentials;
- changing unrelated files; and
- submitting links that cannot be opened.
