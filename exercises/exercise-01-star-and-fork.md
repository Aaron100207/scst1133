# Exercise 1: Star and Fork the Repository

## Overview

In this exercise, you will identify the official SCST1133 repository, star it and create a fork under your GitHub account.

## Learning Objectives

By the end of this exercise, you should be able to:

- identify the official course repository;
- star a GitHub repository;
- fork a repository into your GitHub account;
- distinguish between the original repository and a fork; and
- provide evidence of completed GitHub activities.

## Instructions

### Part A — Open the Course Repository

1. Sign in to your GitHub account.
2. Open the [SCST1133 repository](https://github.com/drshahizan/scst1133).
3. Confirm that the repository owner is `drshahizan`.

### Part B — Star the Repository

1. Locate the **Star** button near the top of the repository.
2. Select **Star**.
3. Confirm that the repository appears in your starred repositories.
4. Capture a screenshot showing that the repository has been starred.

### Part C — Fork the Repository

1. Return to the official SCST1133 repository.
2. Select **Fork**.
3. Choose your GitHub account as the owner.
4. Keep the repository name as `scst1133`.
5. Select **Create fork**.
6. Wait for GitHub to create the fork.
7. Confirm that your username appears in the repository path.
8. Copy the URL of your fork.
9. Capture a screenshot of your forked repository.

## Evidence Required

- Screenshot showing that the official repository has been starred.
- Screenshot of the repository under your GitHub account.
- URL of your forked repository.
- Short explanation of the difference between Star and Fork.
