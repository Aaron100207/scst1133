# SCST1133 Exercises

These exercises introduce the essential GitHub skills required for SCST1133.

## Learning Sequence

| Exercise | Title | Main Skills |
|---:|---|---|
| 1 | [Star and Fork the Repository](exercise-01-star-and-fork.md) | Star, fork and identify repository ownership |
| 2 | [Create a README and Upload Files](exercise-02-repository-and-files.md) | Create repositories, folders, files and commits |
| 3 | [Hello World and Markdown](exercise-03-hello-world-markdown.md) | Write structured technical documentation using Markdown |

## General Requirements

- Use your own GitHub account.
- Follow the required naming conventions.
- Use meaningful file names and commit messages.
- Do not upload passwords, access tokens or private information.
- Submit only your own work.
- Acknowledge external sources and substantial AI assistance.
- Test every file and link before submission.

## Recommended Order

Complete the exercises in sequence:

1. Exercise 1 introduces GitHub repositories, Star and Fork.
2. Exercise 2 introduces repository and file management.
3. Exercise 3 introduces Markdown and technical documentation.

Exercise 1 does not require a Pull Request. Your lecturer will inform you when Pull Request submission begins.
