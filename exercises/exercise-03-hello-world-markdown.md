# Exercise 3: Hello World and Markdown

## Overview

In this exercise, you will create a structured Markdown document containing student information, lists, links, an image, a table, a task list, a blockquote and Hello World code examples.

## Learning Objectives

By the end of this exercise, you should be able to:

- create a Markdown file;
- use headings, paragraphs and text emphasis;
- create ordered and unordered lists;
- insert links and local images;
- create tables and task lists;
- use blockquotes, inline code and fenced code blocks; and
- preview Markdown correctly on GitHub.

## Instructions

### Part A — Create the Markdown File

1. Open your `scst1133-exercises` repository.
2. Select **Add file → Create new file**.
3. Enter:

```text
exercise-03/hello-world.md
```

4. Add the Markdown content provided below.
5. Replace the placeholder information with your details.
6. Preview the document before committing it.

### Part B — Add a Local Image

1. Create this folder:

```text
exercise-03/images/
```

2. Upload a suitable image as:

```text
profile.png
```

3. Confirm that the image appears in `hello-world.md`.
