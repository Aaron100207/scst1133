# Exercise 2: Create a README and Upload Files

## Overview

In this exercise, you will create a personal exercise repository, prepare a README, create a folder, upload a file and examine the commit history.

## Learning Objectives

By the end of this exercise, you should be able to:

- create a public GitHub repository;
- create and edit a README file;
- create folders and text files;
- upload files through the GitHub interface;
- use meaningful file names; and
- write meaningful commit messages.

## Instructions

### Part A — Create a Repository

1. Sign in to GitHub.
2. Select **New repository**.
3. Enter the following repository name:

```text
scst1133-exercises
```

4. Set the repository visibility to **Public**.
5. Select **Add a README file**.
6. Select **Create repository**.

### Part B — Edit the README

Edit `README.md` and add:

```markdown
# SCST1133 Exercises

Name:  
Matric Number:  
Section:  
Course: Data Engineering Ecosystem

## About This Repository

This repository contains my exercises for SCST1133 Data Engineering Ecosystem.
```

Commit the change using:

```text
Create repository README
```

### Part C — Create a Folder and File

1. Select **Add file → Create new file**.
2. Enter:

```text
exercise-02/about-me.txt
```

3. Write a short introduction about yourself.
4. Commit using:

```text
Add student introduction
```

### Part D — Upload a File

1. Prepare one suitable screenshot or image.
2. Rename it using a meaningful filename such as:

```text
github-repository.png
```

3. Open the `exercise-02` folder.
4. Select **Add file → Upload files**.
5. Upload the image.
6. Commit using:

```text
Upload repository screenshot
```

### Part E — Review Commit History

1. Open the repository home page.
2. Select the commit history.
3. Confirm that your commits use clear messages.
4. Capture a screenshot of the commit history.

## Required Repository Structure

```text
scst1133-exercises/
├── README.md
└── exercise-02/
    ├── about-me.txt
    └── github-repository.png
```

## Evidence Required

- URL of the `scst1133-exercises` repository.
- Completed repository README.
- Screenshot of the repository structure.
- Screenshot of the commit history.
- At least three meaningful commits.
- Uploaded file with an appropriate filename.

## Reflection Questions

1. What is the purpose of `README.md`?
2. What information should a useful README contain?
3. What is a commit?
4. Why should commit messages be meaningful?
5. What is the difference between creating and uploading a file?
